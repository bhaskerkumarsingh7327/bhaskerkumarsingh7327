## 🌟 Featured Project

### 🗺️ Google Maps Navigation Simulator

A **Google Maps-inspired navigation system** focused on real-world route planning and graph algorithms.

#### ✨ Features

* 📍 Location Search
* 🗺️ Interactive Map
* 🛣️ Road Network Graph
* ⚡ Shortest Path Calculation
* 🚦 Traffic Simulation
* 🔀 Alternate Route Suggestions
* 📍 Nearby Places
* 🚗 Vehicle Tracking
* 🧠 Graph Algorithms
* 📊 Route Analytics

#### 🔧 Technologies Used

```text
Frontend    → React.js + Vite + Leaflet
Backend     → Node.js + Express.js
Database    → MySQL
GIS         → Python + Shapely + Pyogrio + OpenStreetMap Data
Algorithms  → Graphs + Dijkstra + A* + BFS + DFS
Tools       → Git + GitHub + Postman
```
